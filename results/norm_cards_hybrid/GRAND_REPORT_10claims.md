# Grand experiment — baseline vs norm-card method across 10 claims (gpt-5.5)

**Question (this report):** does sharing the norm card produce a *significant
difference* in the proposed experiments? (Outputs only — no ground-truth scoring yet.)

**Setup (identical for every claim):** SciFy's real flow, replicated on our side
(`norm_cards/scify_proposer.py`, dryrun untouched):
claim → SciFy `DECOMPOSITION_PROMPT` (verbatim) → shared subclaims → SciFy
`SYSTEM_PROPOSER` (verbatim, resource block stripped) → 3 experiments per arm.
**The only difference between the two arms is the norm card** (menu injected via
`current_evidence`). All at gpt-5.5, temp 1.0, n=1.
- Menus (raw): `results/norm_cards_hybrid/problem_X/norm_card.json`
- Recipes (raw, both arms): `results/norm_cards_hybrid/problem_X/scify_proposer.json`
- Cards for 9/10/21 were generated by overriding the `empirical`-only guard
  (they classify as `theoretical`); collection bundles already existed and were reused.

## Per-claim, baseline vs method (one line each)

- **6:** Both decompose into implement→single/multi-family efficacy→capability, both hit **≥3 families and the MMLU/GSM8K/MT-Bench suite** (the claim states them). Method pulls a wider, more current safety-benchmark + judge stack from the menu; baseline uses the standard one. Coverage identical.
- **7:** Both build headline reduction → mechanism ablation → robustness. Method uses the field's current eval infra (SALAD/MD-Judge/ToxicChat); baseline uses older generic sets. No coverage gap; no fabrication either side.
- **9 (obscure):** Both run repeated-trials coverage + non-vacuity tests on MuJoCo, audit the μ-on-D data premise, and certify Lipschitz. **The method arm is the only one in all 10 that explicitly invokes "evidence piece scientific_norm_card,"** and it names the concrete estimator families (GP, Lipschitz-kernel regression, NN-ensembles, PAC/conformal) that the baseline left as "the proposed learning procedure." Clearest card fingerprint of the set.
- **10 (obscure, vague):** Both operationalize the vague claim with conformal prediction / quantile regression / ensembles + coverage-vs-trivial-bound + sample-complexity + distribution-shift. Nearly interchangeable; method adds a LeRobot manipulation dataset.
- **11:** Baseline and method are **near-identical** — both stage clean-eval → train-and-**validate** the illumination CVAE → white-box latent PGD + AP50 degradation. Fully-specified claim; entities carry everything.
- **12:** Both do matched clean-vs-poisoned ASR at 1% poison / >95% trigger, plus a sweep. Method's 3rd experiment adds cross-dataset+architecture generality; baseline's is a poison-rate dose-response. Marginal.
- **21 (obscure/new):** Both nail the hard parts — exact **HMM×DFA product construction** with forward-backward DP verified against brute force, and the fidelity-independence test (poor HMM still 100% DFA-accepted; LLM-likeness tracks fidelity). Method names concrete HMM-fitting methods (Baum-Welch, spectral init, distillation) and CommonGen; baseline stays more generic on fitting.
- **33:** Both do DLA head-selection (sign-flip ≥70%, multiple-comparison correction) → causal ablation/patching with control heads. Method names TransformerLens. Interchangeable.
- **36:** Both do causal tracing → dedicated-storage selectivity → UniEdit reliability/generality>90% + MMLU-collateral<5%, both cite ROME/MEMIT/MEND. **No difference** — on-target menu, but baseline already knows it all.
- **37:** Both do low-rank-subspace probing → constrained latent optimization vs Bayesian-opt baselines (hits/query) → architecture ablation. Method is more concrete on cheminformatics tooling (RDKit SA, AqSolDB, Morgan/Tanimoto-GP).

The method names **more** specific artifacts in 9/10 claims. **Caveat:** the low
overlap is partly **temp=1 run-to-run noise**, not pure card signal — without
baseline-vs-baseline runs (a noise floor) and n>1, the Jaccard numbers can't cleanly
separate "card effect" from "stochastic variance." The reliable signals are the
*qualitative* ones: method consistently names the field's **current/specific** tools,
and #9 literally cites the card.

## Conclusion

**No significant difference in coverage or correctness on any of the 10 claims.**
The baseline is strong everywhere — mainstream, niche, and even the obscure
system-ID (#9/#10) and HMM-DFA-decoding (#21) fields. It never fabricated and never
floundered; gpt-5.5's parametric knowledge already reconstructs the right, correct,
well-staged experiment set from the decomposed claim.

**The card's consistent effect is methodological concreteness/grounding, not
coverage** — it makes the method name the subfield's specific, current tooling
(benchmarks, estimators, algorithms). Crucially, **this effect is largest in the
obscure fields** (#9 cites the card and names GP/kernel/conformal; #21 names
Baum-Welch/spectral/distillation/CommonGen), which is the direction we predicted —
but even there it's *sharpening*, not *rescuing*, because the baseline still gets it
right without the card. The regime where the card would actually change the *outcome*
(baseline fails/hallucinates) was not reached by any of these 10 — every subfield,
however niche, is inside gpt-5.5's knowledge.

Caveats: n=1, temp=1 (single stochastic draw per arm); no ground-truth scoring here.
